# Florida gator editorial

Run the page over HTTP:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000 in your browser. The article links to the matching [News4JAX video on YouTube](https://www.youtube.com/watch?v=kZMENfbDNkU). The original iframe displayed an unrelated older clip and failed to load reliably; this direct link gives readers a playable version. Inline playback can be restored if a permitted MP4 or another embeddable source is available.

Comment text, display names, and displayed dates in `main.js` were checked against the [original News4JAX conversation](https://www.news4jax.com/news/local/2024/04/22/florida-man-uses-bare-hands-to-remove-8-foot-gator-from-busy-road/#commentDiv) on October 12, 2026. ShanF and john marshall are separate comments. Replies retain their own authors and dates.
